# Upstream Dependency Policy

A: Open Notebook (`lfnovo/open-notebook`), SurrealDB engine and Open Notebook worker, pinned source Git SHA and immutable Docker digest during S1; preserve MIT License notice when modifying source UI. S1 private Vault Policy Layer and fault/backup tests are mandatory because upstream API/Auth is not native Course-level authorization.

B: PostgreSQL/Supabase for Course/Grades/Queue, S6 Question/Rubric Contract; optional Math-paper (`Enochan222/Math-paper`) reuse schema, validator and PDF ideas in S11, **not wholesale code or credential flow**. PTH_Homework (`IssacSitHk/PTH_Homework`) marking prototype can inspire S19 benchmark, **not exposed as live security API**.

I: purely authorized A/B API consumers; U: existing Sunrise Teacher Portal only reference, may abandon frontend if unsafe; Lumen Shepherd is UI/RLS role reference (church model not a school schema) and Elephant-Goldfish is review methodology, not executable school app.

Before each implementation stage pin exact commit, version, License and SHA, re-read changed code, test compatibility; these are pointers not proof current GitHub main is safe.
