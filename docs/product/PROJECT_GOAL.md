# Sunrise Goal / Product Intent

Separate A Content Vault (Open Notebook+SurrealDB school materials) and B Learning Operations (PostgreSQL/Supabase courses, generation, synthetic students and later real PII, immutable grades, marking and weakness). Link only through authenticated APIs with a standalone I Service. U is a disposable UI consumer of APIs, not a Data Plane. Every Stage is one owner, independently deployable, regression-tested and backed up; source materials protected by Course grain and immutable version proofs. First trial uses one Admin with secure Session; staff IAM only S22, Teacher A-read S23, real student PII only S25. Examinations eventually support Maths, Chinese, English and General Studies with separate schemas, validators, PDFs and human final approvals. No normal Notebook deletion; School-approved textbooks/notes/past papers live only in A. Use short and reviewable Stage PRs with exact acceptance/rollback evidence.
