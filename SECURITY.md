# Security, Privacy and Secrets — Phased without Waiving Baselines

**S1 A hard release gate:** private Open Notebook native API and privileged UI; only Sunrise Vault Policy Layer reachable by Admin HTTPS; mandatory OPEN_NOTEBOOK_PASSWORD, encryption key, private DB credentials must be non-default, non-empty and available via approved Secret Store at startup or STOP. Native auth absence may skip password checks (observed in uploaded Open Notebook snapshot `api/auth.py`); thus native API must be network-isolated even with password. Database example `root:root` never permitted in deployed environments. Source→Shell→Notebook authoritative catalog and nonempty scoped search, download, preview and SSE checks **before any bytes/LLM context are sent**. Audit 401/403 and failure; backup key-restoration tested without committing key. Single Admin does not mean no security.

**S3 B:** separate Postgres/Supabase credentials/backup, school_id/course_id/actor_id/access_scope from first schema. `service_role` must not be in frontend or I. RLS is defence-in-depth only; DB role privileges and audit also apply. **S4 I:** no DB connection strings, strict A/B service allowlist, signed short-lived service tokens; durable operation state via B API and A journal; QUARANTINED on mismatch. **S7 B:** Gemini key stored server side masked; auth test, model access, quota and live call statuses distinct; no key in queue/log/frontend storage.

**S9 I:** evidence signed, time-bound, limited purpose/sources/excerpts, JWT/JWS-like payload validation plus issuer/audience/nonce/jti/exp/kid and binding+grant revision checks. Call I validation again immediately before B execution and before publishing if evidence status can change. Check A version/published/licence/permission; source excerpts are untrusted data, ignore prompt injection; no privileged tool calls based on retrieved text. No guarantees of atomic cross DB snapshots; fail closed on stale/revoked/unknown state.

**S17 B:** grade events INSERT-only to normal service roles, UPDATE/DELETE forbidden; correction has event/reason/CAS version and DB-enforced single writer ordering. **S22 B:** Staff identities/role/grants/revocation epoch; **S23 I:** teacher read-only A; per request grant & cache invalidation. **S25 B:** school-approved real PII gate. A never stores student/grade/marking/Weakness; B never stores textbook originals. Archive/retention policies begin S1/S2; advanced A/B governance S26/S27. Use AI provider data-processing/legal review before sending copyrighted protected textbooks.
