# Contributing — Public Sunrise Repository (2026-11-14)

The active repository is **public**: `Enochan222/sunrise-school-ai-platform`. Read [AGENTS.md](AGENTS.md), [INSTRUCTIONS.md](INSTRUCTIONS.md), [Security](SECURITY.md), [Stage 1 Limited CI Addendum](docs/decisions/STAGE1_LIMITED_CI_ADDENDUM.md) and the applicable Stage card/Acceptance/API contracts. Historical private-repo, old IssacSitHk, `validate-docs` and blanket no-Actions instructions are superseded as operational guidance; Stage 0 D01–D08 original decisions are not rewritten.

External contributions are proposals, **not authorization** to deploy, handle school/student data, access private Mac services, alter runtime Owner boundaries or merge. Use a narrow branch and PR to protected `main`; declare Stage SNN, single Owner P/A/B/I/U, exact base/head SHA, changed blobs, affected AT/API contracts, security/privacy impact, tested revision, reproducible commands, failures/NOT_RUN, independent review, rollback and Owner release status. A PR to an implementation branch is not covered by the Light CI `main` trigger. No direct protected-main writes, force push, deletion, unattended auto-merge or cross-owner runtime changes. CODEOWNERS is guidance; do not assert unverified mandatory review enforcement.

The only approved Actions workflows are `.github/workflows/stage1-light.yml` (code-path-filtered PRs to `main`, same-repository, `tests/stage1` non-native) and `.github/workflows/stage1-native-integration.yml` (manual, compatibility must be independently established). Never assume a green CI result equals full `pytest tests`, real Native, formal S1-AT01–15, isolated restore, Owner UAT or R01. GitHub Copilot and unapproved workflows/paid usage remain prohibited; $0 Budget and Stop Usage are unchanged. Run `python scripts/run_qa_no_actions.py` for applicable repository document QA and capture exit code and actual output. No real data, secrets, raw evidence, copyrighted originals or backup files in public source/PR/Actions artifacts.

Owner-approved Stage0 D01–D08 and Stage Registry S0–S28 remain authoritative. Stage1 A-only private Gateway/Dual-DB architecture, strict TLS, JWT, CSRF, School/Source IDOR, independent restore and human release gates are mandatory. The Integration Reviewer verifies a live head/tree and content-tested revision before any separately authorized manual squash merge; after merge independently verifies `main`, Git tree and changed blobs. Do not describe a Draft/unmerged PR as delivered or a source review as runtime acceptance.
